# ✅ Aplicación de Lista de Tareas

Una aplicación simple pero poderosa de lista de tareas con funcionalidad de almacenamiento local. Construida con HTML, CSS y JavaScript para máxima compatibilidad y facilidad de uso.

## 🎯 Características

- ✨ Agregar, editar y eliminar tareas
- 💾 Persistencia de almacenamiento local (los datos permanecen después de actualizar)
- ✅ Marcar tareas como completadas/incompletas
- 🔍 Filtrar tareas (Todas, Activas, Completadas)
- 🎨 Interfaz limpia y responsiva
- ⌨️ Soporte de teclado (Enter para agregar, Escape para cancelar)
- 📱 Diseño compatible con dispositivos móviles
- 🌙 Soporte de modo oscuro

## 🚀 Cómo Comenzar

1. Clona el repositorio
2. Abre `index.html` en tu navegador web
3. ¡Comienza a agregar tus tareas!

## 💻 Uso

### Agregar una Tarea
- Escribe tu tarea en el campo de entrada
- Presiona Enter o haz clic en el botón "Agregar"
- Tu tarea se guardará automáticamente

### Gestionar Tareas
- **Completar**: Haz clic en la casilla al lado de una tarea
- **Editar**: Doble-clic en una tarea para editarla
- **Eliminar**: Haz clic en el icono de papelera
- **Filtrar**: Usa los botones de filtro para ver Todas, Activas o Completadas

## 📦 Tecnologías Utilizadas

- **HTML5** - Estructura
- **CSS3** - Estilos con Flexbox y Grid
- **JavaScript (ES6+)** - Lógica de la aplicación
- **API localStorage** - Persistencia de datos
